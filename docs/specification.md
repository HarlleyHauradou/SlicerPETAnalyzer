# Specification — PET Analyzer 0.1

Research image-quality analysis for the six hot spheres of an IEC/NEMA body phantom. The operator selects one- or two-syringe preparation, enters net activity and dilution volumes, and aligns the activity reference with the image reference. A one-syringe preparation assumes a homogeneous stock with no loss beyond the explicitly entered unrecovered stock volume. The source is the stock and the background is the final tank dilution.

The module accepts an already reconstructed scalar volume. DICOM loading and reconstruction are upstream. The operator confirms units, decay reference and geometry. Automatic localization searches for a six-sphere arrangement in the selected axial slab. Labeled manual centers provide a recovery path. Overlay review and confirmation precede reporting. A background ROI is placed independently in the uniform liquid; an optional lung ROI is independently placed in the insert. An optional 12-location planar background template supports five-slice measurements. These measurements are research surrogates and do not implement the complete NEMA NU 2 acquisition and multi-slice ROI sampling procedure.

Outputs include nominal-VOI statistics, 50% background-adapted isocontour recovery, maximum recovery, constrained 1 mL peak recovery, nominal contrast recovery, background variation and optional lung residual. Export produces a printable HTML report, SVG plot, CSV and JSON. Reference ranges are explicit and selectable only for FDG PET; plots identify published comparison bands rather than accreditation. Per-result provenance includes preparation, units, timing, centers and ROI geometry.

Verification uses known synthetic images for exact quantities and failure paths, a public measured PET DICOM fixture for external validation, and Slicer integration checks where the host application is available.
